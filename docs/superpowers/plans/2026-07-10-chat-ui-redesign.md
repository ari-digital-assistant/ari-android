# Chat UI Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the stock-template Android chat into a deliberately-crafted, signature-tier Material You experience — custom type, an ambient presence, "Ari with a face" bubbles, an adaptive empty state, redesigned chrome, and spring motion.

**Architecture:** Frontend-only redesign of `ari-android` (Jetpack Compose + Material 3), plus one additive FFI field (`FfiSkillManifest.examples`) in `ari-engine`. All new decision logic is extracted into **pure Kotlin functions** (JUnit4-tested under `app/src/test/`); Compose composables are thin and verified on the emulator. Dynamic Material You colour is kept and used deliberately — no fixed `ColorScheme`.

**Tech Stack:** Kotlin, Jetpack Compose, Material 3 (+ Expressive motion), Hilt, Kotlin Coroutines/Flow, UniFFI (`uniffi.ari_ffi.*`), Rust (`ari-ffi`, `ari-skill-loader`), JUnit4.

## Global Constraints

- **Scope:** `ari-android` frontend + exactly one additive `ari-engine` FFI field (`FfiSkillManifest.examples`). No behavioural engine change. **No skill changes.**
- **No skill-specific code in the frontend — ever.** Chips/cards are generic host surfaces (HARD RULE).
- **Colour stays dynamic Material You.** Do NOT introduce a fixed `ColorScheme`; use M3 container roles deliberately.
- **Typography:** Manrope (SIL Open Font License), variable, weights 400–800.
- **Strings:** add **English source strings only** to `res/values/strings.xml`. Do NOT invent `values-it/` translations — Keith adds Italian via the normal translation flow. Flag every new string key for translation in the task.
- **Testing:** new logic is **pure Kotlin** (no Android deps) tested with JUnit4 + `org.junit.Assert.*`. Run: `JAVA_HOME=/usr/lib/jvm/java-25-openjdk ./gradlew :app:testDebugUnitTest --tests "<FQCN>"`. There is no Compose UI test harness — visual tasks are verified on the **emulator** (`emulator-5554`), never on Keith's physical Pixel.
- **Gradle needs** `JAVA_HOME=/usr/lib/jvm/java-25-openjdk` on this machine (default daemon misses jlink).
- **Engine push order:** the `ari-ffi` change must be committed + pushed to `ari-engine` main and the Kotlin bindings regenerated **before** the chip task consumes it.
- **UniFFI bindings are NOT auto-generated by gradle** — regenerate manually (see Task A2).
- **"Still working" is dual-channel:** the visual change is text-path only; the spoken filler (`speechOutput.speak`) stays. Never remove the spoken path.
- **Motion respects reduce-motion:** when the system animator duration scale is 0, entrance/ambient animations degrade to instant/static.

package dev.heyari.ari.ui.conversation

import dev.heyari.ari.model.Message

data class MessageRow(
    val message: Message,
    val isFirstInGroup: Boolean,
    val isLastInGroup: Boolean,
    val showTimestamp: Boolean,
)

object MessageGrouping {
    /** Consecutive same-sender messages closer than this fold into one group. */
    private const val GROUP_WINDOW_MS = 60_000L
    /** A quiet timestamp divider is shown when the gap to the previous message exceeds this. */
    private const val TIMESTAMP_GAP_MS = 5 * 60_000L

    fun rows(messages: List<Message>): List<MessageRow> {
        if (messages.isEmpty()) return emptyList()
        return messages.mapIndexed { i, m ->
            val prev = messages.getOrNull(i - 1)
            val next = messages.getOrNull(i + 1)
            val breaksFromPrev = prev == null ||
                prev.isFromUser != m.isFromUser ||
                (m.timestamp - prev.timestamp) > GROUP_WINDOW_MS
            val breaksToNext = next == null ||
                next.isFromUser != m.isFromUser ||
                (next.timestamp - m.timestamp) > GROUP_WINDOW_MS
            val showTimestamp = prev == null ||
                (m.timestamp - prev.timestamp) > TIMESTAMP_GAP_MS
            MessageRow(m, isFirstInGroup = breaksFromPrev, isLastInGroup = breaksToNext, showTimestamp = showTimestamp)
        }
    }
}

    }

enum class VoicePhase { Idle, Listening, Thinking, Speaking }

fun deriveAmbientState(voicePhase: VoicePhase, textThinking: Boolean): AmbientState = when {
    voicePhase == VoicePhase.Speaking -> AmbientState.Speaking
    voicePhase == VoicePhase.Thinking || textThinking -> AmbientState.Thinking
    voicePhase == VoicePhase.Listening -> AmbientState.Listening
    else -> AmbientState.Idle
}

sealed interface GreetingModel {
    data class Named(val part: DayPart, val name: String) : GreetingModel
    object Anonymous : GreetingModel

fun greetingModel(name: String?, hourOfDay: Int): GreetingModel =

    )
